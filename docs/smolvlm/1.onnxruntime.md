# ONNX Runtime

## Official ONNX Model

The official ONNX format model can be downloaded from Hugging Face. Use the model from [an older commit](https://huggingface.co/HuggingFaceTB/SmolVLM-Instruct/tree/a1a065473baa55316b2ddf85ae4e29282d89ad12/onnx) — the newer commit reformatted the model for **WebGPU**, which is not compatible with ONNX Runtime inference.

## Support Status

### CPU (Both Windows and Linux)

ONNX Runtime produces **correct inference results on CPU** for SmolVLM. If CPU-only deployment is acceptable, ONNX is a viable option.

### Windows

ONNX Runtime can run SmolVLM on Windows, but performance is poor:

- The **vision encoder** runs almost entirely on **CPU**
- Other operators also **fall back to CPU** in many cases
- GPU utilization is minimal — overall performance is **far worse than PyTorch**

### Linux

MIGraphX EP **cannot compile** on this device, so ONNX Runtime GPU inference is unavailable. CPU-only inference is possible but not practical.

## Recommendation

ONNX Runtime is **not recommended** for SmolVLM on any platform. Use **PyTorch** instead.

## Working Code

A working inference script using DirectML is available at:

[`models/smolvlm_dml.py`](../../models/smolvlm_dml.py)

This script uses DirectML for the vision encoder and CPU for the decoder/generation loop. It serves as a proof of concept only — do not rely on it for production workloads.
